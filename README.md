This is a repository for a Mini Data Analysis project where I used two different datasets (squirrel data and Rolling Stone 500) to explore the data by asking questions and making plots.

-`boulder-2020-residential_sales.csv` is a csv file where data about homes that were sold in Boulder Colorado
-`coffeeCensus.csv` is a csv file made from a questionare about coffee
-`RollingStone500` is a csv file made from the Rolling Stone top 500 songs
-`squirrel-data.csv` is a csv file made from observer data in new york city of squirrels
